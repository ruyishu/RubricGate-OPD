# 从机制夹具开始

夹具回答的是规则问题，不是「真实 OPD 误罚有多严重」。

```text
python -m unittest research.test_mechanism
python -m research.run_m0
```

输出在 `results/m0-mechanism-001/`。先看 `notes.md`。

正确 DAG 下应当看到：

- 合法换序四步都是正奖励；
- 清单外查询、重复、环境失败、未解锁但没造成破坏，奖励都是 0；
- 平铺清单会给未解锁的付款正奖励；
- c 被错标成依赖 b 之后，合法的先 c 后 b 被打成 0；
- 动作匹配在教师偏爱 b 时，给先做 c 的期望奖励很低；候选数增加不会提高这个期望，只会降低「一次全不中」的概率；
- 付款过早会触发接管，教师补上的子目标不进学生回报；清单外查询不会触发接管。

这些通过，只说明记账和设计一致。

## 下一件该做的事

找一个真实教师，在可换序任务上估计合法动作实际被压分的比例，并和同状态多候选动作匹配对比。比例很小，就停在这里，不写训练。比例很大，再做只打分、不接管的训练对照。接管和早停放在那之后。
