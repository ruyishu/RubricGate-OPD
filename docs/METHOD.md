# 方法

本文件是设计。CPU 夹具只检查了其中的记账规则，没有训练。

## 1. 记号

- 任务 \(x\)，学生 \(\pi_\theta\)，冻结教师 \(\pi_T\)。
- 状态 \(s_t=(x,a_{<t},o_{<t})\)。学生动作 \(a_t^S\sim\pi_\theta(\cdot\mid s_t)\)。
- 动作是一次工具调用，或一条交给环境/用户的消息。一个动作占一段 token。
- 环境返回 \(o_t\)。完成与否只看 \(o_t\) 和已验证子目标，不看动作字符串像不像老师。

## 2. 依赖清单

每个任务有一张 DAG \(\mathcal{G}=(\mathcal{V},\mathcal{E})\)。

- 节点 \(v\) 是可机器验证的子目标，带谓词 \(P_v\)、分值 \(r_v>0\)、前置 \(\mathrm{Pa}(v)\)。
- 边表示硬依赖。没有边相连、前置相同的节点可以换序。
- 已完成集合 \(C_t=\{v:P_v\text{ 已被环境证实}\}\)。
- 已解锁集合 \(\mathcal{U}_t=\{v\notin C_t:\mathrm{Pa}(v)\subseteq C_t\}\)。

清单没覆盖到的动作不是错误。它可能是查询、准备或重复调用。只有环境证实「破坏了已完成子目标」，或者学生执行了尚未解锁的提交类动作，才进入下面的违规分支。提交类由任务声明，例如付款；提前查询一个还没解锁的只读接口不是提交。

构造来源仍未定，按这个顺序试：工具 schema 里能被环境断言检查的节点；教师轨迹生成候选后再滤掉永远验不出来的节点；退化为一条链，只做对照。DAG 画错会直接教错。实验要单独报错误标注下的误伤，不能只报完美标注。

## 3. 第一版：只打分，不改路径

学生动作照常执行。奖励不看它是否等于教师动作。

\[
R_t=
\begin{cases}
r_v & o_t\text{ 新证实了某个 }v\in\mathcal{U}_t\\
-1 & o_t\text{ 破坏了某个已经证实的节点}\\
0 & \text{其他}
\end{cases}
\]

其他包括：清单外动作、重复、环境没生效、尚未解锁但没有造成破坏。最后一种奖励是 0，但标签仍是 `dependency_block`，留给第二阶段的门控。不要把这个 0 写成负样本。

师生字符串一致也不能跳过环境。一致但 \(o_t\) 没证实子目标时，\(R_t=0\)，节点不能写入 \(C_t\)。

这一版的正奖励和「势能只在证实/破坏时变化」是同一类信号。DARS 已经用前置依赖做分步奖励，所以第一版不把「DAG 打分」写成新贡献。它的作用是先把合法、中性、破坏这三类分开，供后面的门控使用。

## 4. 第二阶段：门控（未训练）

只在需要改变后续采样时使用。默认预算 \(M\) 先按 1 设计。

| 标签 | 决定 | 环境 |
|---|---|---|
| 新完成已解锁子目标 | 继续 | 保留学生动作 |
| 清单外、重复、没生效、未解锁的非提交动作 | 继续 | 保留学生动作，奖励仍按第 3 节 |
| 未解锁的提交动作，或破坏了已完成子目标，且介入次数 \(<M\) | 接管 | 丢掉学生动作的环境效果，改执行教师的一个已解锁动作 |
| 上一行的情况但预算用尽 | 早停 | 停止这条 rollout |

接管时教师动作不参加学生的 log-probability。教师刚刚证实的子目标记在单独的 `teacher_progress` 里。

## 5. 回报怎么切

第一版轨迹全是学生动作，可以用普通回报

\[
G_t=\sum_{k\ge t}\gamma^{k-t}R_k+\gamma^{T-t}R_{\mathrm{outcome}}
\]

再做组内标准化。训练代码还没写。

第二版不能沿用这条式子。接管把轨迹切成两段：

- 被替换的学生动作只拿它自己的 \(R_{t^\*}\)。后面的教师进展、后续学生奖励和终局奖励都不加进来。
- 接管之前的学生动作，回报在 \(t^\*\) 截断。
- 接管之后的学生动作，只累计接管之后的学生奖励和终局奖励。
- 教师动作没有学生梯度。

原因：终局是教师帮忙之后才到达的。把这段回报加给被换掉的动作，等于把代打的进展算成学生的功劳。夹具检查了这个记账，没有检查它能不能训稳。

## 6. 还不做

- 不模仿教师的思考文本，也不要求同一个词表。
- 不把「不在 \(\mathcal{U}_t\) 里」直接当负奖励。
- 不在错误 DAG 上把方法说成有效。错误标注是必报的对照。
- 不把第一版的打分结果写成超过 DARS 或 GraphOPD 的训练收益。
