# 方法

本文件是设计。CPU 检查只覆盖奖励符号、老师何时出现、KL 系数、候选奖励和回报切断，没有训练。

## 1. 监督单位

学生自己采样。第 \(t\) 步是一段 token，里面可以有思考和一次工具调用或一条消息。环境返回 \(o_t\)。

评分点描述状态，不描述动作。例如「读到了订单 O123」「订单的航班已改成目标航班」。每个点有：

- 检查方式：优先是查库或跑测试；不能程序化时才用模型判断，并缓存结论。
- 前置评分点。
- 种类：只读，或提交。提交点的权重高于只读点。设计起点是只读 0.2、提交 1.0，这两个数没有调过。
- 权重 \(w_v>0\)。

已成立集合只收环境证实的点。清单没写到的查询、准备、重复调用不是错误。尚未解锁的只读尝试也不是错误。尚未解锁就做提交动作，或者弄坏了已经成立的点，才是错误。

评分点由老师写：给它任务、工具说明、几条走法不同的成功轨迹，以及几条学生的失败轨迹。写完做四项过滤：成功轨迹上必须成立，否则删点；两条成功轨迹里顺序相反的两点之间删掉依赖边；一开始就成立的点删掉；检查方式能改成程序的就改成程序。依赖图写错会直接教错，实验要单独报。

老师的知识主要装在评分点里。所以「老师写的评分点」和「不看老师轨迹写出的评分点」必须对照，见 EXPERIMENTS 的 H6。

## 2. 逐步奖励

\[
r_t=\sum_{v\in\mathrm{New}_t}w_v-\sum_{v\in\mathrm{Broken}_t}w_v
\]

没有变化时 \(r_t=0\)。这里不看动作字符串是否等于老师。字符串一致但环境没生效，仍然是 0，点也不能算成立。

终局成功奖励 \(R_{\mathrm{out}}\) 一直保留。只奖励中间进展时，学生可能学成「只查不办」。

## 3. 老师在哪些状态出现

只在两类状态上问老师：

- **确认出错**：弄坏了已成立的评分点，或者尚未解锁就做提交动作。
- **卡住**：连续 \(K\) 步没有任何评分点变化，包括本步。设计起点 \(K=3\)，没有调过。

偶尔一步没变化，可能是清单外的必要准备，老师不出现。连续多步不动，更像迷路，这时才让老师拉一把。推进了的步，老师永远不出现。

## 4. 损失

\[
\mathcal{L}=\mathcal{L}_{\mathrm{PG}}+\beta\sum_t g_t\,\mathrm{KL}_t+\lambda\,\mathcal{L}_{\mathrm{fix}}
\]

\(\mathcal{L}_{\mathrm{PG}}\) 是按步优势的裁剪策略梯度。同一步里的 token 先平均，再共享这一步的优势，避免长思考盖过短调用。组内标准化沿用同题多条轨迹。

**白盒老师。** \(\mathrm{KL}_t\) 只算第 \(t\) 步学生自己生成的 token，方向是对老师的反向 KL。算它需要师生同一套词表。开关是：

| 本步情况 | \(g_t\) |
|---|---|
| 新成立了评分点 | 0 |
| 偶尔一步没变化，或尚未解锁的非提交动作 | 第一次训练用 0；另做小正数的消融 |
| 卡住 | 1，设计起点，没调过 |
| 弄坏了已成立的点，或尚未解锁就提交 | 1 |
| 早停之后的 token，以及老师代打的 token | 不进入损失 |

**黑盒老师。** 拿不到概率时，不在原轨迹的那一步上比较「像不像老师」：出错步上学生的动作本来就错，和老师一致要么不会发生，要么说明评分点写错了。改为在老师出现的状态上，让学生重新采样 \(N\) 个候选，每个候选在环境副本里执行一次：

- 推进了评分点：奖励 1，不管老师会怎么做；
- 弄坏了已成立的点：奖励 0；
- 其他：奖励是它和 \(K_T\) 个老师采样的语义一致比例。

候选在这个状态上组内标准化，再做策略梯度。候选不继续往下跑，原轨迹也不受影响。

这一步和 ActionOPD 的区别是两点：只在出错或卡住的状态上做，不是每个状态都做；评分点上的推进排在「像老师」之前，所以另一种合法做法不会因为和老师不同而被压到更低。它要求环境能复制，\(\tau^2\)-bench 可以复制数据库，代码题可以复制工作目录。环境不能复制时只剩一致比例，合法替代就可能被压分，这种环境不进主实验。

\(\mathcal{L}_{\mathrm{fix}}\) 只在后一阶段、而且真的发生纠正时才有：在出错状态上，让学生提高老师那个正确动作的概率，

\[
\mathcal{L}_{\mathrm{fix}}=-\log\pi_\theta(a^T_{t^\*}\mid s_{t^\*}).
\]

不模仿老师的整条轨迹，也不模仿思考文本。

第一阶段训练只有 \(\mathcal{L}_{\mathrm{PG}}\) 和老师信号（白盒用 KL，黑盒用候选），不改采样路径，\(\lambda=0\)。必须同时跑三种：老师信号全程打开、从不打开、按本节规则打开。规则版不优于全程打开，这套规则就不能写成贡献。

## 5. 后一阶段的路径

默认最多纠正 1 次。

| 情况 | 做法 |
|---|---|
| 推进了，或只是没变化 | 学生继续 |
| 尚未解锁的非提交动作 | 学生继续 |
| 尚未解锁就提交，或弄坏了已成立的点，且还有纠正预算 | 丢掉该步的环境效果，老师执行一个已解锁动作，再交还学生 |
| 上一行但预算用完 | 停止这条轨迹 |

卡住本身不触发纠正，只打开老师信号。老师完成的评分点记在 `teacher_progress`，不能加进学生奖励。

## 6. 回报切断

没有纠正时，学生每步的回报是其后的 \(r_k\)，终局奖励接在最后一步：

\[
G_t=\sum_{k\ge t}\gamma^{k-t}r_k+\gamma^{T-1-t}R_{\mathrm{out}}.
\]

在 \(t^\*\) 纠正一次时：

- \(t<t^\*\)：只累计到 \(t^\*-1\)，不看被替换的那一步，也不看终局奖励。
- \(t=t^\*\)：只有 \(r_{t^\*}\)。
- \(t>t^\*\)：只累计纠正之后的学生奖励和终局奖励。

早停没有老师代打，前缀按普通回报算到停止步，终局奖励一般是 0。停止之后没有 token。

这些式子写在 `research/loss_spec.py`，由 `research/test_loss_spec.py` 检查。它们没有在模型上跑过。

## 7. 还不做

- 不把「不在评分点里」写成负奖励或负的 KL。
- 不在评测时用这套评分点代替基准自己的成功判定。
- 不把脚本夹具的低分写成真实老师的误罚率。
- P0 没过门槛之前，不写训练器。
