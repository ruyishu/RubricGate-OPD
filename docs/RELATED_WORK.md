## 监督粒度

| 层级 | 代表 | 监督在问什么 | 多轮 agent 上还没盖住的部分 |
|---|---|---|---|
| token | 主流 OPD | 每个 token 像不像老师 | 措辞、顺序、做法不同都会进 KL |
| action | ActionOPD，2610.19820，2026-10-14 | 当前状态下这一步像不像老师抽到的动作 | 换序、换工具、拆开调用仍可能低分。我们的论点是：动作一致也不等于环境办成 |
| 评分点，整份一次 | ROPD，2605.07396，2026-05-08 | 整份回答满足几条评分点 | 实验主要是数学、医学、科学和指令跟随。一份回答一个分，没有按环境步更新 |
| 评分点，按步 | 本仓库要做的 | 这一步让哪个状态成立，或破坏了哪个 | 尚未训练 |

ROPD 的评分点来自老师和学生回答的对比，再用它给 rollout 打分，从而不必读取老师 logit。原文把 logit OPD 说成 token 模仿，把评分点 OPD 说成传递结构化原则。这个框架不能再说成空位。这里和它的差别要落在多轮环境的逐步打分，以及老师只在出错或卡住时进入梯度。

## 定位

ActionOPD 决定这一步像不像老师。GraphOPD 决定这一步多学还是少学。DARS 决定这一步推进了多少。ROPD 用评分点给整份回答打分。

这里把评分点写成状态，按环境步更新奖励，只在确认出错或卡住时才让老师进入梯度。黑盒老师时，在这些状态上局部重采样学生候选，推进了评分点的候选排在「只是像老师」的候选之前；这和 ActionOPD 每个状态都按一致程度打分不同。纠正和早停使用同一个出错判断。

在和 ROPD 的整卷打分、DARS 的逐步奖励、全程打开的老师信号、不看老师轨迹写出的评分点比较出差别之前，不写「首次」。
