## 一句话定位

现有工作要么「按 token/步与教师对齐（会被换序误伤）」，要么「按整条轨迹/集合打分（丢掉依赖与密集信号）」。
本项目要做的是：**用 DAG 形式的 rubric 把「依赖」和「可交换」显式写出来，在分叉点用 rubric 判推进，据此决定放行 / 改造 / 早停。**

## 需要继续查的重叠风险

- 「rubric + 早停」的组合是否已有人做（本轮检索只找到 RELAY 用 rubric 选样本）；
- 「可交换动作 / 偏序」在 agent RL 侧是否已有形式化（关键词：commutative subgoal、partial order reward、state confluence）；
- τ²-bench / ALFWorld 上是否有人报过「换序轨迹被 OPD 判负」的定量证据。

在没查清这三条之前，不对外声称「首次」。
