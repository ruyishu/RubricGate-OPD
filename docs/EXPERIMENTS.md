# 实验设计

跑过的只有 CPU 检查。下面的探针和训练都没做。不写预期涨点。

## 命题

- **H1，未验证。** 真实老师下，「不同但没错」的步会被 token KL 和同状态动作匹配压分。脚本夹具不能证明这件事。
- **H2，只检查了规则。** 环境证实的新评分点得正分；没变化得 0；弄坏已有评分点得负分。老师只在确认出错或卡住时出现；推进步的老师信号为 0。黑盒候选里，推进了评分点的候选不会排在「只是像老师」的候选之下。
- **H3，未验证。** 同一学生、同一数据和同一预算下，按步评分点训练优于整条轨迹打一次分，并且不差于 DARS。评测用基准自己的成功判定。
- **H4，未验证。** 同样的逐步奖励下，老师信号按「出错或卡住」打开，优于全程打开，也优于从不打开。
- **H5，未验证。** 在相同干预预算下，按评分点纠正或早停，优于按师生分歧做同样的干预。老师代打的进展不进学生回报。
- **H6，未验证。** 老师写的评分点，优于不给老师轨迹、只看任务和工具说明写出的评分点；有 DARS 手写图的环境，也和手写图比。否则「老师的知识装在评分点里」不成立，方法就只是过程奖励的 RL。

## 开跑前写死的门槛

下面的数是判断，不是从数据里调出来的。跑完不能改；要改，先写下理由并重跑。

### P0：真实轨迹上的不一致

数据：\(\tau^2\)-bench retail 训练集至少 50 题，学生每题 4 条轨迹。学生经过的每个状态上，老师贪心解码 1 次，另外按温度 1 采样 4 次。

不一致步：学生动作和老师贪心动作语义不同。用贪心定义，是为了让「4 次采样里有没有学生的做法」仍然可以量，不会因为定义而恒为 0。

至少标 300 个不一致步，不够就加题。每步标一类：

| 标签 | 判定 |
|---|---|
| 顺序不同 | 学生本步让某个已解锁评分点成立；老师贪心动作指向另一个已解锁评分点 |
| 换工具 | 师生指向同一个评分点，工具或参数不同 |
| 粒度不同 | 学生分几步完成老师一步完成的评分点，或者反过来 |
| 多了无害步骤 | 本步不让任何评分点成立也不破坏，之后的轨迹仍然推进 |
| 走错 | 弄坏已成立的评分点，或尚未解锁就提交；之后还能救回来 |
| 关键步走错 | 走错，并且在这一步的环境副本上让老师接手跑 3 次，3 次都失败 |
| 无法判断 | 以上都不确定 |

两名标注者独立标同一批 100 步，Cohen's κ 至少 0.6 才使用标签；不够就先改定义。第二名标注者如果是模型，要单独注明。

压分的量法：

- **token 侧**，只有白盒老师才有：一步里每个 token 的 \(\log\pi_T-\log\pi_\theta\) 取平均。参照组是同一批数据里「学生动作和老师贪心一致」的步。某步低于参照组的第 10 百分位，算被压分。
- **动作侧**：学生动作和老师 4 次采样语义一致的次数。最多 1 次一致，算被压分。

通过条件，两条都要满足：

1. 前四类，也就是「不同但没错」，占全部不一致步至少 20%；
2. 前四类里，至少在一侧被压分的比例至少 50%。

不满足就停，不写训练器。同时报告「走错」和「关键步走错」在两侧的分数，看 OPD 信号能不能抓住真错。

### P1：评分点质量

至少 50 题，用 P0 里人工标好的步做参照：

- 人工标为「不同但没错」的步，被评分点判成出错的比例不超过 10%；
- 人工标为「走错」或「关键步走错」的步，被评分点判成出错的比例至少 70%。

同时报告过滤掉的坏点比例和每题老师调用次数。不过就先改生成流程。

### P2：只打分的训练

至少 3 个种子，同一批评测题。成功率差用按题配对的 bootstrap 求 95% 置信区间。

- 「优于」：区间下界大于 0。
- 「不差于」：区间下界不低于 -2 个百分点。

通过条件：优于整条轨迹打一次分的同一套评分点，并且不差于 DARS。H4 和 H6 的结论按同样的标准写。

## 阶段

1. **P0 探针。** 见上。
2. **P1 评分点质量。** 先用 \(\tau^2\)-bench 和带单元测试的代码题。
3. **P2 只打分的训练。** 不纠正、不早停。对照：终局 GRPO、ActionOPD、白盒 token OPD、同一套评分点但整条轨迹打一次分、DARS、不看老师轨迹写出的评分点。老师信号的三种开法都要跑。
4. **P3 路径干预。** 只有 H1 成立才做。对照是「只打分」和「按分歧、用同样预算干预」。然后换第二个基准，并消融平铺评分点、人工评分点、故意写错的评分点、中性步的 KL 权重、卡住步数 \(K\)、纠正项系数。
