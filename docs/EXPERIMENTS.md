# 实验设计

**本文件全部是计划与假设，没有任何已跑出的数字。**

## 1. 要证伪/证实的三条命题

- **H1（现象）**：在含可交换子目标的任务上，token 级 OPD 与基于 token 分歧的早停方法，会给「合法换序」的轨迹施加显著负信号；换序率越高，损害越大。
- **H2（机制）**：把「是否推进」的判据从「与教师 token 一致」换成「命中已解锁 rubric 节点」后，上述误伤消失，且不牺牲对真错误的识别。
- **H3（收益）**：改造（而非直接早停）让长轨迹后半程状态被访问到，成功率与样本效率同时提升。

## 2. 基准

| 基准 | 为什么选 | 可交换子目标 |
|---|---|---|
| τ²-bench（retail / airline） | 多轮工具调用、有明确状态机、可造偏序 | 需要自己标注 |
| ALFWorld | 与 STRIDE/TASPO/SOPD 可直接比 | 取放顺序部分可交换 |
| WebShop | 与 MENTOR/ROPD 可比 | 查询条件顺序可交换 |
| 自建 toy 环境 | 精确控制依赖与可交换度，做因果归因 | 全可控 |

toy 环境是 pilot 的核心：动作是符号化的，`a` 无前置，`b`/`c` 前置为 `a` 且互不依赖，`d` 前置为 `b` 且 `c`；教师策略带顺序偏好（例如 0.8 走 `b` 先），可精确测量「教师顺序偏好强度」对蒸馏的影响。

## 3. 对照

- Outcome RL：GRPO / GiGPO
- 稠密蒸馏：token 级 OPD（reverse-KL）、ActionOPD、SOPD
- 早停/接管派：STRIDE、TISD（若可复现）
- 轨迹/集合派：MENTOR 式工具集合一致、ROPD 式整轨迹 rubric
- 本项目消融：
  - Flat Rubric（去掉前置依赖）vs DAG Rubric
  - 只放行 / 只改造 / 只早停 / 三态全开
  - $M\in\{0,1,2\}$（最大改造次数）
  - 快路径开关（是否只在分叉点调用评判器）

## 4. 指标

主指标：任务成功率、pass^k。
诊断指标（本项目的重点，比主指标更能说明问题）：

1. **误杀率 False-Penalty Rate**：合法换序轨迹被判负或被早停的比例（需人工/规则标注的合法集合）。
2. **分叉存活率**：发生换序后，轨迹活到终局并成功的比例。
3. **后段节点覆盖率**：最后一步（如 `d`）在训练早期被真实访问到的频次。
4. **Rubric 一致率**：DAG 判定的可解路径与真实可解路径不一致的比例（方法本身的上界）。
5. 效率：每成功一次的环境步数、生成 token 数、wall-clock、评判器调用次数。

## 5. 预期结果（假设，不是结论）

以 Qwen3-4B/8B 为学生：

- 在强顺序依赖任务上，与 ActionOPD / STRIDE 持平；
- 在可交换子目标占比较高的任务上，成功率高于 token-OPD 与 STRIDE，预期 3–6 个点（这个区间只是按 ActionOPD 报告的增益量级推的，没有依据保证）；
- 误杀率显著低于 token-OPD / STRIDE；
- 由于早停与快路径，训练 token 吞吐优于全量 OPD。

**任何一条没出现，就按结果写，不改实验去凑。**
